# Чат-бот для фиксации клиентов от риэлторов (ВКонтакте + Битрикс24 + Яндекс Таблицы)

Проект разработан в строгом соответствии с **Техническим заданием № 1** (Заказчик: СТС Групп) и предназначен для развёртывания в социальной сети **ВКонтакте (VK)**. Бот позволяет внешним партнёрам (риэлторам) оперативно и без ошибок фиксировать переданных клиентов.

---

## 🚀 1. Возможности и архитектура

- **Идентификация риэлтора:** Запрашивает ФИО (с валидацией не менее 2 слов) и название агентства. Данные сохраняются в сессии SQLite (`sessions.db`) на срок **не менее 24 часов** и не требуют повторного ввода при передаче новых клиентов.
- **Пошаговый сбор данных клиента:** Валидация ФИО клиента и номера телефона (от 10 до 12 цифр, автоматическая очистка от пробелов, скобок, дефисов и приведение к формату `+7...`).
- **Сводка и редактирование:** Кнопки «Всё верно» / «Исправить» перед фиксацией. Можно точечно исправить любое поле без сброса остальных данных.
- **Двойное сохранение в Яндекс Таблицу:** Каждая запись добавляется с автоматической меткой времени в локальную копию `realtor_clients_backup.csv` и в облачную таблицу (Яндекс Диск / Таблицы при наличии токена).
- **Интеграция с Битрикс24 (REST API):** Создание лидов через метод `crm.lead.add` с полями `TITLE`, `NAME`, `PHONE`, `COMMENTS`.
- **Отказоустойчивость (Retry & Alerting):** При ошибке или недоступности API Битрикс24 фоновый воркер повторяет отправку через 5 минут (до 3 раз). При окончательном сбое администратору отправляется уведомление по электронной почте.
- **Логирование:** Все диалоги и ошибки записываются в папку `logs/` (`bot.log` и `errors.log`).

## 🛠 2. Установка и запуск в PyCharm

1. Откройте папку проекта `Project_Client_Realtor` в **PyCharm**.
2. Убедитесь, что настроено виртуальное окружение Python 3.10+ (`.venv`).
3. Установите зависимости через терминал PyCharm:
   ```bash
   pip install -r requirements.txt
   ```
4. Скопируйте файл конфигурации `.env.example` в `.env` и укажите ваши ключи (см. ниже).
5. Запустите бота:
   ```bash
   python main.py
   ```
   > **Подсказка:** Если ключи ВКонтакте ещё не указаны, бот автоматически запустится в удобном **интерактивном консольном режиме (CLI mode)** для тестирования логики диалога прямо в терминале PyCharm! Вы также можете запустить этот режим явно командой: `python main.py --cli`.

## 🔑 3. Администрация и замена ключей (`.env`)

Все параметры подключения вынесены в файл `.env` (создаётся на основе `.env.example`):

- **ВКонтакте:**
  - `VK_GROUP_TOKEN` — токен сообщества (получить: Управление сообществом -> Работа с API -> Ключи доступа).
  - `VK_GROUP_ID` — цифровой ID сообщества (например, `123456789`).
- **Битрикс24:**
  - `BITRIX_WEBHOOK_URL` — URL входящего вебхука с правами `crm` (например, `https://your_company.bitrix24.ru/rest/1/xxxxxxxxx/`).
- **Яндекс Таблицы / Документы:**
  - `YANDEX_OAUTH_TOKEN` — OAuth-токен для доступа к Яндекс Диску.
  - `YANDEX_SHEET_PATH` — путь к таблице на Яндекс Диске (`/Таблицы/Фиксация_клиентов_СТС_Групп.xlsx`).
- **Уведомления администратора:**
  - `ADMIN_EMAIL` — e-mail администратора, куда будут приходить тревожные уведомления.
  - `SMTP_USER` и `SMTP_PASSWORD` — учётные данные для отправки писем.

## 📝 4. Редактирование текстов и сообщений

Для редактирования приветствий, подсказок и формулировок **не нужно менять основную логику кода**. Все тексты собраны в одном файле:
- 📂 **`bot/texts.py`** — здесь находятся классы и константы с текстами диалогов (например, `WELCOME_REALTOR_FIO`, `ASK_AGENCY`, `SUCCESS_FIXED`).

Для изменения кнопок и меню:
- 📂 **`bot/keyboards.py`** — генерация клавиатур для ВКонтакте (`VkKeyboard`).

---

## 🧪 5. Запуск автоматизированых тестов

В проект включён полный набор модульных тестов (`pytest`) для проверки валидаторов, конечного автомата (FSM), сохранения сессий и интеграций:
```bash
pytest
```
Тесты проверяют корректность обработки ФИО, номеров телефонов, сброса сессий (`/reset`, `/cancel`) и формирование корректного JSON-payload для Битрикс24 и Яндекс Таблиц.
